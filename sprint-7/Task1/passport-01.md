# Паспорт № 1. Подозрительные операции

## 1. Инициатива

| Поле | Решение |
|---|---|
| Инициатива | Операция и доступная история → рекомендация о месте операции в очереди финансового мониторинга |
| Какое действие изменится | Сотрудник получает очередную операцию по приоритету, учитывающему подозрительность, а не только сумму |
| Где нужна обучаемая закономерность | Оценка отклонения от привычного поведения клиента; подготовка истории, обязательные проверки и очередь — обычный код |
| Допущения | Результат используется для приоритета проверки. Переход к автоматической блокировке требует отдельного решения |
| Вердикт | Гибрид |

## 2. Постановка

| Поле | Решение |
|---|---|
| Объект и единица решения | Одна операция |
| Момент | В реальном времени, при поступлении операции в поток проверки |
| Операция | Аномалия: оценить нетипичность отдельной операции |
| Модальность | Таблица и время: атрибуты операции и история операций клиента |
| Выход модели | Числовая оценка нетипичности операции, используемая как один из сигналов при расчёте приоритета ручной проверки |
| Бизнес-выход | Операция в очереди ручной проверки с приоритетом, основаниями и ссылками на исходные сведения; решение по операции принимает сотрудник |
| Источник правильного ответа | Достоверных меток «схема / не схема» мало. Модель сравнивает новую операцию с предыдущим поведением клиента. Подтверждённые нарушения и операции с незавершённой проверкой исключаются из обучающей истории; её состав уточняется по итогам расследований. Отсутствие подтверждения не доказывает безопасность |
| Конвейер | Код: подготовка истории → модель: оценка отклонения → код: объединение с другими сигналами и правилами приоритета → сотрудник: проверка → код: уточнение обучающей истории |
| Альтернативные постановки | Автоматически задерживать подозрительные операции или пропускать остальные без участия сотрудника. Уточняющий вопрос: система только определяет приоритет ручной проверки или самостоятельно решает, проводить ли операцию? |

Операция не входит в историю, с которой сравнивается. Исключение из обучения не удаляет её из банковского учёта. Модель обновляется отдельно; при нехватке истории действуют правила.
