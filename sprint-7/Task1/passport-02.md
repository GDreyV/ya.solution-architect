# Паспорт № 2. Распознавание текста кредитных документов

## 1. Инициатива

| Поле | Решение |
|---|---|
| Инициатива | Скан или фотография кредитного документа → текст с привязкой к странице и области оригинала |
| Какое действие изменится | Андеррайтер исправляет проблемные области; успешно прошедший согласованные проверки текст принимается автоматически, часть результатов проверяется выборочно |
| Где нужна обучаемая закономерность | OCR. Проверки файла, хранение и отображение выполняет программа |
| Допущения | Предполагается, что текст распознаваем, не рукописный. Результат № 2 — текст, а не подтверждённые финансовые показатели; их анализ и оценка относятся к № 18 |
| Вердикт | Гибрид |

## 2. Постановка

| Поле | Решение |
|---|---|
| Объект и единица решения | Страница документа; результат объединяется в документ |
| Момент | После загрузки документа, асинхронно; результат нужен к разбору кредитного пакета |
| Операция | Извлечение: распознать текст |
| Модальность | Документ и изображение: сканы и фотографии страниц |
| Выход модели | Текстовые блоки, их координаты и оценка уверенности |
| Бизнес-выход | Оригинал и распознанный текст рядом; проблемные области доступны для исправления |
| Источник правильного ответа | Расшифровка отдельной выборки страниц, сверенная с оригиналом до оценки OCR; в эксплуатации — исправления сотрудника и выборочный контроль |
| Конвейер | Код: подготовка страниц → модель: OCR → код: постобработка и проверки, включая результаты № 18 → автоматическое принятие либо сотрудник: разбор исключений и выборочный контроль |
| Альтернативные постановки | Под оцифровкой можно понимать заполнение полей кредитной заявки данными из скана |
