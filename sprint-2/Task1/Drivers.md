# Архитектурные драйверы — AdScale

| Категория                 | Драйвер                         | Значение                                                 |
| ------------------------- | ------------------------------- | -------------------------------------------------------- |
| Функциональное требование | Интеграция с DSP-партнёром      | Поддержка OpenRTB bid requests / responses               |
| Функциональное требование | RTB-аукционы в реальном времени | Обработка не менее 18 000 RPS                            |
| Функциональное требование | Сбор статистики                 | Обработка потока кликов и показов                        |
| Функциональное требование | Аналитика и отчётность          | Формирование отчётов без деградации RTB                  |
| Атрибут качества (P0)     | Latency                         | P95 ≤ 100 ms (целевое ≤ 80 ms для DSP)                   |
| Атрибут качества (P0)     | Availability                    | Непрерывная работа платформы, минимизация downtime       |
| Атрибут качества (P0)     | Reliability                     | Отсутствие потери bid requests и event data              |
| Атрибут качества (P1)     | Scalability                     | Масштабирование до 50 000 RPS в течение года             |
| Атрибут качества (P1)     | Performance Isolation           | Разделение RTB, analytics и statistics workloads         |
| Атрибут качества (P2)     | Deployability                   | Возможность постепенного rollout без остановки платформы |
| Техническое ограничение   | Текущий стек                    | C++, Go, Python, Node.js, PostgreSQL                     |
| Техническое ограничение   | Legacy архитектура              | Гибридный монолит с общей БД                             |
| Техническое ограничение   | Инфраструктура                  | Один production-кластер, ручной деплой                   |
| Техническое ограничение   | Команда                         | ~35 сотрудников без выделенной SRE/platform команды      |
| Бизнес-ограничение        | Сроки                           | Промежуточное решение должно быть готово за 3 месяца     |
| Бизнес-ограничение        | Бюджет                          | Ограничен, невозможен полный rewrite системы             |
| Бизнес-ограничение        | Непрерывность бизнеса           | Нельзя останавливать RTB-платформу во время миграции     |
| Бизнес-ограничение        | SLA DSP-партнёра                | Штрафы за рост latency и downtime                        |
