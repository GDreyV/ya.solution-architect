# 1.1. Ключевые бизнес-сущности

| Сущность | Описание и основные атрибуты | Связи | Источники | Критерий включения | Проблемы качества |
|---|---|---|---|---|---|
| Клиент | Физическое или юридическое лицо: идентификатор, имя или наименование, ИНН, паспортные и контактные данные, сегмент | Договор, счёт, карта, кредит, обращение | FU CRM, RB CRM, FU Core Banking, RB Core | Нужен единый профиль клиента | Дубли, разные идентификаторы и форматы, пропуски, устаревшие контакты |
| Договор | Юридическое основание обслуживания: идентификатор, номер, даты, статус, клиент, продукт | Клиент, продукт, счёт, кредит | FU Core Banking, RB Core, FU Loans, RB Loans | Связывает клиента с продуктом | Разные номера, статусы и модели |
| Счёт | Банковский счёт: идентификатор, номер, валюта, статус, баланс, клиент | Клиент, договор, карта, операция, платёж | FU Core Banking, RB Core | Критичен для обслуживания и отчётности | Разные модели и статусы, несогласованные остатки |
| Карта | Платёжная карта: идентификатор, маскированный номер, статус, тариф, срок действия, счёт | Счёт, клиент, продукт, операция | FU Cards, RB Cards | Нужна для объединения карточных продуктов | Разные статусы карт и тарифы |
| Кредит | Кредитное обязательство: идентификатор, договор, сумма, ставка, срок, статус, остаток | Клиент, договор, продукт, платёж | FU Loans, RB Loans | Важен для продукта, риска и отчётности | Разные правила продуктов и статусы |
| Операция | Движение средств: идентификатор, дата и время, сумма, валюта, тип, статус, счёт | Счёт, карта, платёж | FU Core Banking, RB Core, FU Cards, RB Cards | Основа финансовой отчётности | Дубли выгрузок, разные коды и форматы времени |
| Платёж | Распоряжение на перевод: идентификатор, плательщик, получатель, сумма, дата, статус | Счёт, операция, клиент | FU Core Banking, RB Core | Отдельно отражает жизненный цикл платежа | Разные статусы, пропуски реквизитов |
| Продукт | Банковское предложение: код, название, тип, условия, статус | Договор, счёт, карта, кредит, тариф | FU Core Banking, RB Core, FU Cards, RB Cards, FU Loans, RB Loans | Нужна единая продуктовая линейка | Несогласованные коды и названия |
| Тариф | Условия и стоимость обслуживания: код, продукт, период действия, комиссии | Продукт, карта, договор | FU Cards, RB Cards, FU Core Banking, RB Core | Тарифы прямо названы источником расхождений | Разные коды, версии и периоды действия |
| Обращение | Контакт клиента: идентификатор, канал, тема, текст, статус, дата | Клиент, договор, продукт | FU CRM, RB CRM | Нужен единый контекст обслуживания | Дубли, неструктурированный текст, разные темы и статусы |
| Отделение | Точка обслуживания: код, название, адрес, статус | Клиент, договор, обращение | FU CRM, RB CRM, FU Core Banking, RB Core | Справочник явно требует синхронизации | Разные коды и написание адресов |
