# 1.5. Сопоставление с референсной моделью BIAN

BIAN (Banking Industry Architecture Network) используется как ориентир для единых терминов и границ банковских областей.

Источник областей: [BIAN Service Landscape V9.1 — Matrix View](https://bian.org/servicelandscape-9-1/views/view_30526.html) — открытое представление официального каталога сервисных доменов BIAN.

| Сущность | Близкая область BIAN | Польза |
|---|---|---|
| Клиент | Party Reference Data Directory | Единая трактовка данных клиента и граница владения профилем |
| Обращение | Customer Case Management | Общая модель работы с обращениями |
| Счёт | Current Account | Унификация модели счёта двух банков |
| Карта | Issued Device Administration | Согласование статусов и жизненного цикла карты |
| Кредит | Loan | Общие границы кредитных данных |
| Платёж | Payment Order | Единый жизненный цикл платёжного поручения |
| Операция | Financial Accounting | Согласованное отражение финансовых проводок |
| Продукт | Product Directory | Единый каталог банковских продуктов |
| Договор | Customer Agreement | Единое понимание соглашения с клиентом |
