# 4.3. Cutover-план домена «Клиентские данные»

Полной остановки клиентских сервисов нет. Короткое ограничение изменений касается только объединяемых атрибутов профиля; обращения и финансовые операции продолжаются.

| Шаг | Действия | Критерий успеха / фолбэк |
|---|---|---|
| Подготовка | Проверить MDM, Integration Layer, доступы и мониторинг; создать резервную копию клиентских записей и таблицу соответствия идентификаторов | Тестовая загрузка и обратный поток завершены без критических ошибок |
| Data freeze | На время финальной синхронизации запретить изменение сопоставительных атрибутов клиента в RB CRM; новые изменения сохранить в очереди | Очередь принимает изменения, обслуживание продолжается |
| Финальная выгрузка | Выгрузить изменения RB CRM после последней полной загрузки | Количество записей и контрольные суммы совпадают с источником |
| Загрузка | Проверить формат, сопоставить клиентов, загрузить новые версии золотых записей в MDM | Все записи имеют результат: объединены, созданы или направлены на ручную проверку |
| Сверка | Сравнить количество клиентов, уникальные идентификаторы, обязательные поля, дубли и выборку профилей | Порог критических ошибок — ноль; спорные совпадения не объединяются автоматически |
| Переключение | Направить чтение единого идентификатора через MDM; снять ограничение и обработать очередь изменений | CRM и потребители получают актуальную версию профиля |
| Фолбэк | Вернуть маршруты чтения на прежние CRM, остановить публикацию MDM, восстановить таблицу соответствия, проиграть сохранённую очередь после исправления | Исходные записи не изменены и доступны для обслуживания |
| Мониторинг | Контролировать задержку синхронизации, ошибки, число дублей, неподтверждённые сообщения и обращения сотрудников | Усиленный контроль до стабильной работы и завершения бизнес-сверки |
