# 4.1. Образ целевого результата

| Вопрос | Целевое состояние через 12 месяцев |
|---|---|
| Какие системы остаются | FU CRM, FU Core Banking, FU Cards, FU Loans, DWH, BI, Data Lakehouse, MDM, Integration Layer, Kafka, Airflow, DataHub |
| Какие выводятся | RB CRM, RB Core, RB Cards, RB Loans, RB DWH, RB BI и точечные интеграции — после миграции соответствующих данных и подтверждения критериев |
| Какие данные мигрируются | Клиенты, договоры, счета, карты, кредиты, операции, платежи, обращения и справочники RetailBank |
| Какие потоки переключаются | Клиентские данные — на MDM; операционные интеграции — на Integration Layer и Kafka; аналитические загрузки — в общий DWH и Lakehouse; BI — на единые витрины |
| Что подтверждает завершение | Сверены количество записей, финансовые суммы и остатки; нет критических ошибок; единый идентификатор используется; отчёты согласованы; происхождение данных доступно; дублирующие системы не принимают новые изменения |

Отключение выполняется по доменам, а не одновременно. Архивные данные сохраняются в объектном хранилище и Lakehouse согласно их назначению.
