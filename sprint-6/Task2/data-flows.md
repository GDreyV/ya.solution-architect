# 2.3. Потоки данных через три месяца

Диаграмма использует расширенную нотацию CRUD: `C` — создание, `R` — чтение, `U` — обновление, `D` — удаление, `A` — агрегация, `E` — обогащение, `V` — валидация. Цвета и расширение `A/E/V` используются во всех потоках диаграммы. DAMA-DMBOK используется как общий источник подхода к управлению интеграцией и потоками данных: [Data Integration and Interoperability в DAMA-DMBOK](https://dama.org/dmbok2r-infographics/).

Диаграмма: [data-flow.mmd](diagrams/data-flow.mmd).

| Источник | Приёмник | Сущности | Действие | Режим | Назначение |
|---|---|---|---|---|---|
| FU CRM, RB CRM | MDM Customer Hub | Клиент | Read, Validate, Enrich, Create, Update | Асинхронный, близкий к реальному времени | Прочитать исходные записи, сопоставить клиентов и сохранить золотую запись с единым идентификатором |
| MDM Customer Hub | CRM, Core и Loans двух банков | Клиент | Read, Update | Асинхронный | Распространить единый идентификатор и золотые атрибуты |
| MDM Customer Hub | Integration Layer | Клиент | Read | Пакетный | Передать золотую запись клиента для единой отчётности |
| Core, Cards, Loans двух банков | Integration Layer | Счёт, договор, карта, кредит, операция, платёж, продукт, тариф | Read | Пакетный и асинхронный | Получить операционные данные через единый интеграционный слой |
| Integration Layer | DWH | Клиент, счёт, договор, продукт, тариф, операция, платёж, кредит, карта | Validate, Enrich, Create | Пакетный | Подготовить и сохранить единые данные отчётности |
| DWH | BI | Согласованные данные и витрины | Read, Aggregate, Create | Пакетный | Сформировать витрины и предоставить единую управленческую аналитику |
| DWH | Регуляторная отчётность | Регламентированные наборы | Aggregate, Read | Пакетный | Формирование отчётности |
| MDM, Integration Layer, DWH | DataHub | Метаданные и происхождение данных | Create, Update | Пакетный | Каталог, владельцы и трассируемость |
| DataHub | Data Office, ИТ, аналитики | Метаданные и происхождение данных | Read | По запросу | Поиск наборов данных, владельцев и источников показателей |

Удаление финансовых фактов потоками не выполняется. Удаление клиентской записи в MDM означает прекращение публикации, а не физическое удаление истории.
