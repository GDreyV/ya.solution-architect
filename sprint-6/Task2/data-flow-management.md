# 2.4. Управление потоками данных

| Источник → приёмник | Сущность и действие | Формат | Частота / тип | SLA | Владелец | Контроль качества | Безопасность и мониторинг |
|---|---|---|---|---|---|---|---|
| FU CRM, RB CRM → MDM | Клиент: Read, Validate, Enrich, Create, Update | JSON | Близко к реальному времени, асинхронно | 5 минут | Data Office | Дубли, обязательные идентификаторы, формат контактов | Шифрование, разграничение доступа; задержка и ошибки сообщений |
| MDM → CRM, Core, Loans | Клиент: Read, Update | JSON | Близко к реальному времени, асинхронно | 5 минут | Data Office | Наличие единого идентификатора, версия записи | Шифрование, аудит; неподтверждённые сообщения |
| MDM → Integration Layer | Клиент: Read | Табличная выгрузка | Ежедневно, пакетно | До загрузки DWH | Data Office | Единый идентификатор, версия золотой записи | Шифрование, разграничение доступа; полнота выгрузки |
| Core двух банков → Integration Layer | Счёт, договор, платёж, операция, продукт: Read | Табличная выгрузка | Ежедневно, пакетно | До начала рабочего дня | ИТ | Количество строк, суммы, контрольные итоги | Защищённый канал; статус загрузки и сверки |
| Cards двух банков → Integration Layer | Карта, карточная операция, продукт, тариф: Read | Табличная выгрузка | Ежедневно, пакетно | До начала рабочего дня | ИТ | Статусы, ссылка на счёт, суммы, дубли | Шифрование; ошибки загрузки и расхождения |
| Loans двух банков → Integration Layer | Кредит, продукт: Read | Табличная выгрузка | Ежедневно, пакетно | До начала рабочего дня | ИТ | Остаток, срок, договор, клиент | Шифрование, доступ по ролям; полнота загрузки |
| Integration Layer → DWH | Согласованные данные: Validate, Enrich, Create | Табличная выгрузка | Ежедневно, пакетно | После получения данных источников | ИТ | Полнота, допустимые форматы, контрольные итоги | Защищённый канал; ошибки преобразования и загрузки |
| DWH → BI через пайплайн витрин | Витрины: Read, Aggregate, Create | SQL | Ежедневно, пакетно | После загрузки DWH | Финансовый департамент | Сверка метрик с DWH | Доступ по ролям; свежесть витрин |
| DWH → регуляторная отчётность | Отчётные наборы: Read, Aggregate | Регламентированная выгрузка | По графику отчётности | По сроку отчёта | Финансовый департамент | Контрольные суммы и бизнес-сверки | Аудит выгрузок; успешность формирования |
| MDM, Integration Layer, DWH → DataHub | Метаданные: Create, Update | Метаданные | Ежедневно, пакетно | 24 часа | Data Office | Владелец, описание, происхождение | Ролевой доступ; доля описанных наборов |
| DataHub → Data Office, ИТ, аналитики | Метаданные: Read | Пользовательский и программный интерфейсы (API) | По запросу, синхронно | Время ответа интерфейса | Data Office | Актуальность владельца, описания и происхождения | Ролевой доступ; доступность каталога и ошибки запросов |
