# Сравнение регионов

Источник: [условие Task4](../artifacts.md#artifact-3), [проверенные ранее тарифы Task2](../Task2/options-comparison.md).

## Assumptions

Сравнение использует сохранённые сведения. Цена — USD PAYG без новых запросов к поставщикам. В колонке задержки указано наличие замеров из Нигерии/Кении/ЮАР. Поддержка конкретного SKU в зоне требует проверки.

| Провайдер / регион | Сервисы-кандидаты | Замеры latency NG/KE/ZA | Проверенная цена | Условия SLA | Вывод |
|---|---|---|---|---|---|
| AWS af-south-1, Cape Town | EC2, S3, RDS; доступность нужных SKU уточнить | Нет | Нет | EC2 99,99% при выполнении условий размещения в ≥2 AZ | Кандидат для ЮАР; нигерийскую локализацию не закрывает |
| Google africa-south1, Johannesburg | Compute Engine, Cloud Storage; конкретные managed-сервисы уточнить | Нет | Нет | Compute Engine: multi-zone 99,99% при условиях SLA | Альтернатива для ЮАР |
| Azure South Africa North | VM, Managed Disks; глобальные DNS/Front Door отдельно | Нет | D16as v5 16 vCPU/64 GiB: $668,68/мес., без дисков | VM 99,99% при ≥2 VM в ≥2 AZ | Пример облака в смете; публичная статика MVP |
| Layer3 / HOSTAFRICA, Lagos | VM, диски, IP; PostgreSQL самостоятельно | Нет | Layer3 16 vCPU/32 GB/512 GB: $208,09; HOSTAFRICA C9 16 vCore/64 GB/500 GB: $277,67/мес. | SLA выбранных тарифов: Нет | Основной контур MVP по принятой границе данных |

Цены локальных VM включают разные объёмы памяти/дисков; это ориентиры конкретных конфигураций. Измерение перед выбором: HTTPS и RTT из трёх целевых стран, P50/P95 в течение суток. Победитель по задержке или цене среди трёх облаков пока не определён.

Для MVP выбираются локальные нигерийские VM; Azure используется как пример CDN/DNS. Адреса и условное распределение площадок приведены в Task2. Для ЮАР сравнение уточняется перед запуском страны.
