# 3.3. API предстоящих записей

Используется URL-версионирование `/api/v1`: оно явно для мобильного клиента и позволяет параллельно поддерживать несовместимую следующую версию. Пагинация `limit`/`offset` подходит для ограниченного списка предстоящих записей и проста в использовании клиентом; сервер ограничивает `limit` значением 100. Фильтр `status=upcoming` оставлен явным, хотя этот endpoint ориентирован на будущие записи.
